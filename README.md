# ¿Te protege la ley?

Test interactivo que acompaña la entrada sobre el **Cyber Resilience Act** y la **Directiva NIS2** de [El rincón de Alberto y Leti](https://elrincondealbertoyleti.com/).

- Página estática: un único `index.html`, sin dependencias ni seguimiento.
- No guarda ni envía ningún dato: todo se calcula en el navegador.
- Política de seguridad de contenido (CSP) restrictiva con hashes para el script y los estilos.

Actualizado a noviembre de 2026.
